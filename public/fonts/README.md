# Notebook opening font

`zhanglu-notebook.woff2` is a renamed, web-only subset of LXGW WenKai,
obtained from `@fontsource/lxgw-wenkai@5.3.0` (500 normal).
Source: https://github.com/lxgw/LxgwWenKai
Distribution: https://www.npmjs.com/package/@fontsource/lxgw-wenkai
License: SIL OFL 1.1; see OFL.txt for the complete original copyright and license.
The derivative font's internal family name is Zhanglu Notebook.

Included text: 记录、在路上、做自己。张路
Only the desktop opening and signature use this font. No system installation
or external font request is required. If the opening or signature changes,
regenerate the subset with the new text; missing glyphs use the CSS fallback.
