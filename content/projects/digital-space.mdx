## 项目背景

在信息时代，拥有一个属于自己的数字空间变得越来越重要。我想创建一个平台来展示我的思考、项目和经历。

## 技术方案

- **前端**：Next.js 15 + TypeScript + Tailwind CSS
- **内容管理**：MDX 文件 + GitHub
- **部署**：Vercel（自动部署 + CDN）
- **SEO**：SSG + 结构化数据 + llms.txt

## 设计理念

极简风格，专注内容。使用蓝色作为点缀色，营造干净、安静的阅读环境。

## 成果

- 零成本运营（$0/月）
- 内容管理简单（编辑 MDX 文件即可）
- 优秀的 SEO 和 AI 可发现性
- 移动端友好的响应式设计
