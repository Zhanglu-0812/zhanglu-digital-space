# 内容提供与确认流程

从 2026-09-12 起适用。最终展示标题、首页简介和图片位置由张路明确提供或逐项确认；Codex 可以给候选，不将候选自动当作定稿。适用于新增内容及修改已有内容。

## 固定流程

1. 张路提供原文及图片，按下方表单填写有把握的项目；其他项目写「请给候选」或「暂不使用」。
2. Codex 整理一份待确认卡，标明本人原文、候选文案、图片位置与尚未明确的字段。正文默认不改写，必要的明显改写单独列出。
3. 张路逐项修改或明确「这篇/这批按清单确认」。局部确认只适用于对应字段或内容，不扩大为其他条目的确认。
4. Codex 按确认结果更新本地页面，执行检查，提供预览。缺少标题或配图安排的新内容先留本地草稿，不擅自补写后上线。
5. 张路验收本地排版。验收与上传分开：只有当次明确授权提交和上传，才执行发布流程。

当前页面的素材标题来自原始文件，首页简介与配图位置包含此前整理方案，仍需按此次新流程复核，详见 `CONTENT_REVIEW.md`。复核期间保持本地现状，不擅自删除或替换。

## 文章确认模板

复制以下内容填写，可直接在聊天里回复：

```text
文章：原文件名或当前文章标题
最终展示标题：
首页简介：希望读者在首页看到的一小段话
发布日期：YYYY-MM-DD
首页代表文章：是 / 否
标签：
正文：使用哪个文件、版本，或直接粘贴
正文修改范围：保持原文 / 仅排版 / 指定修改段落
封面：准确图片文件名 / 暂不使用
配图安排：
- 图片文件名：
  位置：放在“某个小标题”之后，或“某句话/某段话”之后
  图注：具体文字 / 不显示
- 其他图片按同样格式补充
未列出的图片：暂不使用
确认结果：确认以上内容 / 还需要调整……
```

文章主标题默认在首页、列表与详情页一致；「首页简介」对应文章摘要，目前三处共用。若希望某处不同，请明确指出。保留已有文章网址，改标题不自动改网址。封面固定放在详情页标题、摘要与标签之后，正文之前；如需调整也写进表单。原始图片文件保持不变，网页转换与大小优化不改变图文含义。

## 思绪确认模板

```text
思绪：原序号或当前标题
最终展示标题：
记录时间：YYYY-MM-DD HH:mm（知道几位就填写几位）
标签：
正文：原笔记 / 指定版本 / 直接粘贴
图片与位置：图片文件名＋具体位置 / 无
确认结果：确认以上内容 / 还需要调整……
```

思绪可以批量确认标题，用「01 → 新标题」的方式回复；保留标题的条目也请明确范围，例如「02—06 保留」。标题不由 Codex 自动改写。标签若由 Codex 整理，也列出供本人确认。

页面顺序固定为：记录时间 → 标题 → 标签 → 正文。正文不超过 100 字完整展示；超过 100 字默认折叠，预览前 100 字，保留「展开思绪」，展开后切换为「收起思绪」。计数按去掉常见 Markdown/HTML 标记后的正文非空白字符，标点、数字、英文字母各计一个字符；标题、标签与图片地址不计入。首页与思绪页使用相同规则。

## 个人介绍确认模板

「首页简介」如果指网站顶部自我介绍，使用单独表单，避免与文章摘要混淆：

```text
公开姓名：
一句话介绍：
首页个人简介：
同步关于我：是 / 否（如有事实变动，列出具体位置）
确认结果：
```
